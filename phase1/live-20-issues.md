# live-20 issues log (template)

Copy or append dated notes to **local** `data/reports/live-20-issues.md` after a manual practice round-trip. That path is gitignored (`data/`). **No secrets. No keys. Not a forecast.**

Example:

```
## 2026-09-04
- read-only snapshot: avail DOGE=… avail USDC=…
- --roundtrip --sz 50: sell state=… buy state=…
- leftover cancel? yes/no
- notes:
```
